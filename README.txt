ABOUT:
CleoAI is an Open-Source local AI model developed in Windows VBScript.
Cleo consists of a single perceptron (the AI equivalent of a brain cell)
that answers one question: Should you go outside? Although, no AI
even Cleo, is perfect, so please, do not rely on Cleo to determine if
you should actually go outside. (I mean, seriously, if you need AI to
determine if you should go outside, you rely on AI too much). Besides
all of that, enjoy using Cleo! And a fun fact, this txt file has almost
the same number of lines as Cleo has lines of code!
-The developer of CleoAI
